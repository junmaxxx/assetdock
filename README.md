# 素材坞 · AssetDock

一个本地素材索引工具：把电脑上的图片、视频、音频、PDF/PPT 扫成一份 SQLite 索引，用相册的方式浏览，双击就能放大看、在窗口里播放，或查看文档封面。

**默认只读。** 媒体文件始终留在原来的文件夹里，程序只记录"在哪、多大、什么时候改的"，再生成一份缩略图缓存。只有你主动点右键里的复制 / 剪切 / 重命名 / 删除 / 整理，才会操作真实文件；删除进入软件自己的待删除箱，保留 7 天，可按 `Ctrl+Z` 撤销。

## 下载（Windows 免安装）

到 [Releases · v1.6.4](../../releases/tag/v1.6.4) 下载 `assetdock-win64-v1.6.4.zip`，解压到一个固定目录，双击 `素材坞.exe` 即可。不需要装 Python，首次启动会先扫盘并显示进度。

## 功能

- **相册式首页**：最近 7 天 / 最近 30 天 / 全部 / 图片 / 视频 / 音频 / 文档 / 动图，以及按来源自动分的相册
- **两层分类**：先按大分类（游戏素材、产品物料、聊天图片、下载、截图…），再按项目内细分（背景、道具、动作帧、AI 生图…）；规则都在 `库服务.py` 的 `CAT_RULES` / `sub_of()` 里，可按自己的目录改
- **筛选与搜索**：类型、分类、位置、磁盘（C: / D: / E:…）、细分叠加筛选，按文件名、完整路径或正文内容搜索；还能按方图 / 竖图 / 横图、透明底、短视频筛选
- **标签与收藏**：给单个或多个素材加标签，按标签建相册；星标收藏，首页有「★ 我的收藏」
- **待删除箱与撤销**：删除统一进入 `00_索引/待删除`，按日期和批次存放，保留 7 天；可勾选还原，恢复原路径、标签和收藏；`Ctrl+Z` 撤销上一批删除
- **重复与相似清理**：完全重复按文件指纹分组（小文件 SHA-256，大文件用大小+首/中/尾抽样指纹）；相似图按 64 位 dHash 分组。每组可「保留最佳、清理其余」，全局一键只清理完全重复项，避免误删相似但不同的素材
- **批量整理**：批量重命名（`{name}` / `{n}` / `{date}` 模板，自动保留扩展名、避免覆盖）、批量移动（可创建目标目录、同名自动加序号）、批量转 WebP/JPG（保留原图，输出目录可选）
- **批量选择**：点「批量选择」或卡片右键「多选」进入，单击 / Ctrl / Shift 连选；底部只显示已选数量和退出多选，**删除必须右键选中项并二次确认**，不会“选中即删”
- **内容搜索**：Windows 自带 OCR 识别截图/表情包里的中英文字，PDF 抽前 30 页正文、PPTX 抽文本框；搜索框同时匹配文件名、路径和正文
- **全局快捷键**：`Ctrl+Alt+Space` 随时唤起窗口并把焦点放到搜索框
- **运行更快**：分类统计和相册列表按数据版本缓存；扫描、查重、内容索引都是低优先级后台任务；重复分析优先复用已有缩略图，第二次打开直接走缓存
- **不碰云盘占位文件**：WPSDrive、WPS Cloud、OneDrive、Dropbox、Google Drive、iCloud Drive、百度网盘、坚果云等同步目录在遍历前就整目录跳过；遇到 Windows 云占位文件也直接跳过，避免扫描触发客户端下载
- **文档封面**：PDF 渲染首页；PPTX 取第一页里的图片；取不到图或老 `.ppt` 生成带文件名的占位封面。双击文档看大图封面，右键仍可用系统程序打开
- **无限滚动**：按年月分段，每页 120 条，滚到底自动续
- **内置图片查看器**：双击打开，滚轮缩放、拖动平移、适应窗口 / 1:1、上一张 / 下一张、键盘快捷键
- **全编码播放（mpv）**：浏览器内核播不了的视频，双击会直接打开随包携带的 mpv 独立窗口；MOV/MKV/AVI、HEVC/H.265、AV1、10bit HDR 都能直接解。也可以右键「用内置播放器打开」或点查看器里的同名按钮。不再先转 540p，省掉等待，也避免 ProRes/10bit 转坏
- **H.264 MP4 仍走网页播放器**：mp4 / m4v / webm 里的 H.264 直接内嵌播，进度条可拖动；关掉素材坞不影响已经打开的 mpv 窗口
- **右键菜单**：查看 / 播放、用系统程序打开、用内置播放器打开（全编码）、打开文件所在位置、复制文件、剪切文件、重命名、收藏 / 标签、批量整理、删除到待删除箱、复制完整路径、复制文件名、属性
- **文件操作**：复制 / 剪切写入 Windows 剪贴板（资源管理器里可直接粘贴，剪切带移动效果）；重命名只改当前这一层文件名，自动保留扩展名；删除进入软件待删除箱
- **界面缩放**：Ctrl + 滚轮 50%~300%，右下角有百分比滑块，比例本地记忆
- **零黑窗**：视频首帧用内置 ffmpeg 抽取，`CREATE_NO_WINDOW` 静默执行
- **单实例**：重复启动只会把已有窗口叫到前面
- **首扫进度页**：显示已扫文件数、用时、第几个盘、当前目录

## 支持格式

| 类型 | 格式 |
| --- | --- |
| 图片（直接显示） | jpg / jpeg / png / gif / webp / bmp / svg / avif / ico |
| 图片（服务端转码后显示） | tif / tiff / psd / heic / heif / jxl |
| 视频 | mp4 / mov / mkv / webm / avi / m4v / flv / wmv / mpg / mpeg / ts（按首字节过滤 TypeScript 源码） |
| 音频 | mp3 / wav / m4a / ogg / flac / aac / wma / opus |
| 文档（封面预览） | pdf / pptx / ppt（老 .ppt 为占位封面，需系统 Office/WPS 才能取真封面） |

超过 150 MB 的图片不做内嵌解码，会提示改用系统程序打开。

## 快速开始（源码运行）

需要 Windows 10/11、Python 3.10+（开发时用的是 3.13）。

```bash
python -m venv _工具/py
_工具/py/Scripts/pip install -r requirements.txt

# 起原生窗口（WebView2）
_工具/py/Scripts/python 库服务.py gui

# 或者只起本地服务，用浏览器打开 http://127.0.0.1:8765/
_工具/py/Scripts/python 库服务.py serve
```

第一次启动会自动扫描并显示进度页。之后每 15 分钟自动补扫一次。

Windows 也可以直接双击 `启动素材坞.bat`（会使用 `_工具\py` 里的解释器）。

## 扫描范围与跳过

复制示例文件后按需修改，一行一个：

```bash
copy 扫描范围.example.txt 扫描范围.txt
copy 跳过目录.example.txt 跳过目录.txt
```

- `扫描范围.txt`：从这些目录开始递归。不写则默认所有本地固定硬盘 + 当前用户目录。
- `跳过目录.txt`：路径里含这些关键词的整棵目录跳过（Windows、Program Files、node_modules、微信/QQ 缓存、WPSDrive/OneDrive 等云盘等）。

## 数据都在哪

| 路径 | 内容 |
| --- | --- |
| `00_索引/library.db` | SQLite 索引（WAL） |
| `00_索引/缩略图/` | 360px 缩略图缓存，可随时删 |
| `00_索引/预览缓存/` | psd/heic 等转码后的 PNG，可随时删 |
| `00_索引/播放缓存/` | 非 MP4 视频转出来的 MP4，30 天没播自动清，可随时删 |
| `00_索引/待删除/` | 软件内删除的文件，按日期/批次存放，保留 7 天，可还原 |

`00_索引` 只在本机，**不要提交到 git**（里面有完整本地路径）。`.gitignore` 已经排除。

## 打包成 exe

```bash
pyinstaller --noconfirm --clean --onedir --noconsole ^
  --icon icon.ico --name 素材坞 ^
  --add-data "app.html;." --add-data "icon.ico;." --add-data "_工具\mpv;mpv" ^
  --collect-all webview --collect-all imageio_ffmpeg --collect-all pillow_heif ^
  --collect-all pypdfium2 --collect-all pypdfium2_raw ^
  --collect-submodules winrt --collect-submodules pythonnet --hidden-import clr --hidden-import clr_loader --hidden-import cffi ^
  库服务.py
```

成品在 `dist/素材坞/`，整个文件夹拷走即可运行，不需要装 Python。

## 已知限制

- 仅支持 Windows（窗口依赖 WebView2；服务端本身是纯 Python）
- 复制 / 剪切只写剪贴板，不搬文件；剪切后在资源管理器粘到别处，库里的旧路径要等下一次补扫（≤15 分钟）才更新
- 删除是移到软件待删除箱，保留 7 天；勾选「清空待删除」才会永久删除
- 首次全盘扫描耗时取决于磁盘文件量，之后都是增量
- 重复分析首次只处理小图、文档和已生成缩略图的图片；上亿像素的超大图、云盘占位文件、超过 64 MB 的大文件和移动硬盘休眠文件会自动跳过，浏览生成缩略图后再分析会更全
- 相似图采用 64 位 dHash，阈值较严且只显示 2~20 张的组；相似但不同的素材请逐组人工确认，不要用「清理完全重复项」处理
- HEVC/H.265、AV1、MOV、MKV 等网页内核播不了的视频，双击或右键会交给随包的 mpv 直接播；mpv 是独立窗口，不是嵌在素材坞界面里
- mpv 独立窗口不嵌在素材坞界面里，是单独一个播放窗口；关掉素材坞后它仍可继续播
- OCR 使用 Windows 自带语言包，需要系统安装「简体中文」OCR 能力；PDF 正文只抽前 30 页，扫描版 PDF 没有文本层时不额外做 OCR
- `psd` 只读合成图，不解析图层
- PPTX 封面只取第一页里最大的图片；纯文字页、老 `.ppt` 会显示占位封面，不会调用 Office 渲染
- 分类靠路径关键词，目录命名不规范时会落到「其他」
- 安装包内置 mpv 播放器（约 116 MB），因此 v1.6.2 的压缩包明显比之前大；mpv 按其 GPLv2+ 许可证分发，源码见 https://github.com/mpv-player/mpv
